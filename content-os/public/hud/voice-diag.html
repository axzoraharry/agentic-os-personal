Voice diagnostics

Temporary tool for checking the mic path. Must be served from http://localhost:3950 — a LAN IP is not a secure context and both mic paths will fail there.

Server voice endpoints

Round-trips real audio: synthesises speech via /api/assistant/speak, then feeds that audio back into /api/assistant/transcribe. This is what decides whether the HUD uses the server path or falls back to the browser.

Microphone

"Both together" is the case the automated tests could not cover: the level meter opens its own getUserMedia while the recognizer runs its own capture. If the meter moves and a transcript arrives, concurrent capture works.
